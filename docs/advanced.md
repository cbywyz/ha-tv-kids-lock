# 进阶玩法：每日配额 / 分时段 / 续杯 / 周报

> 这部分是「基础三道锁」之上的精细化管控。基础篇（音量锁 / 信号源锁 / 定时锁）看 [README](../README.md) 第三～五章就够日常使用；想进一步按「每天能看多久、什么时段能看、能不能讨价还价」来管，再来看这里。
>
> 所有自动化完整 YAML 都在仓库根目录的 `tv_lock_automations.yaml` 的「进阶篇」段落；本文讲**机制与坑**，具体代码以 yaml 为准（通知示例用飞书，换成你自己的推送服务即可）。

---

## 1. 每日观看配额

**机制**：电视处于「播放中」状态时，用一条 `time_pattern` 自动化每分钟给 `input_number` +1，累计「今日已看分钟」。

> 为什么不用 HA 自带的 `history_stats` 传感器？因为它**没有 reload 服务**，改配置必须重启 HA 才能生效——家长管控经常要调，重启太重。用一个 `input_number` 自己累加，改完 `automation reload` 即可。

- 今日已看 ≥ 配额 → 自动上锁 + 推通知「今天看了 X 分钟，超额，已锁定」。
- 每天 **0:01** 把今日分钟并入「本周累计」后清零，进入新的一天。

对应 yaml：`tv_quota_tick`（每分钟 +1）、`tv_quota_check`（超配额上锁）、`tv_quota_daily_rollup`（0:01 并入周累计并清零）。

## 2. 分时段模式（四档 input_select）

用一个 `input_select`（如 `tv_mode`）收拢四种状态，避免满屏开关：

| 档位 | 行为 |
|------|------|
| **常规** | 基础锁照常，可续杯 |
| **作业模式** | 一上锁就锁死，**3 秒内自动锁回**、**不给续杯**（防孩子用「再看 5 分钟」磨） |
| **睡眠模式** | 电视一开机就关（到点强制休息） |
| **今晚自由** | 一键全家豁免，今晚不锁 |

- 每晚 **22:30** 自动切「睡眠」、早 **7:00** 回「常规」（两条 `time_pattern` 自动化）。
- 切档时同步修正相关锁状态（如进作业模式立即上锁）。

对应 yaml：`tv_mode_set_*`（各档切换）、`tv_mode_nightly`（22:30 睡眠）、`tv_mode_morning`（7:00 常规）。

---

## 3. 再看 5 分钟（续杯）

孩子到点被锁，偶尔想「再看一会儿」：家长解锁 → **5 分钟后自动重新锁**。

- 用一个 `input_number` 记「今日续杯次数」，**每天最多 2 次**，用完直接拒绝并通知。
- **作业模式下不给续**（见上一节）——否则作业模式会被续杯悄悄破掉。

对应 yaml：`tv_snooze_5min`（解锁后启 5 分钟计时）、`tv_snooze_check`（次数限制）。

---

## 4. 每周周报

- 每周一早 **9:00** 推一条上周观看汇总：本周累计分钟 + 日均。
- 推完把「本周累计」清零，开始新一周。

对应 yaml：`tv_weekly_report`（周一 9 点触发）。

---

## ⚠️ 关键避坑

1. **定时解锁别破作业模式**：「倒计时结束后自动解锁」那条自动化，条件里必须加「当前不是作业模式 **且** 配额未用尽」，否则作业模式下会被定时解锁悄悄解开。
2. **续杯受模式约束**：续杯只在非作业模式生效；作业模式下的锁应靠「3 秒锁回」兜底，而不是靠续杯逻辑。
3. **计数重置时点**：今日配额每天 0:01 清零、续杯次数建议也在 0:01 重置、周累计周一 9 点推完清零——三处时点别重叠写错，否则会出现「昨天的时间算到今天」。

## YAML 索引（按功能找自动化）

| 功能 | `tv_lock_automations.yaml` 中的 automation id 关键字 |
|------|------|
| 每日配额累加 / 检查 / 日结 | `tv_quota_tick` / `tv_quota_check` / `tv_quota_daily_rollup` |

| 周报 | `tv_weekly_report` |
